# Veritas-AI

Welcome to the Veritas-AI

This autonomous multi-agent system uses advanced LLMs to conduct deep, citation-backed research on any topic you give it.

## How it works:
1. **Planning:** An agent breaks down your topic into specific search queries.
2. **Searching:** An autonomous web searcher scours the internet, extracting content and scoring sources for credibility.
3. **Synthesizing:** The agent analyzes the high-quality sources and extracts key findings.
4. **Writing:** A specialized writer compiles the findings into a comprehensive, multi-section report with citations.

To get started, simply type a research topic or question in the chat box below!
